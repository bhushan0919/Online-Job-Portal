## 📌 Overview

**Online Job Portal** is a web-based application designed to provide a convenient platform for job seekers to explore employment opportunities and interact with job application workflows.

The application focuses on providing a responsive and user-friendly interface with dedicated pages for user registration, login, job listings, job details, and job applications.

Built using HTML5, CSS3, JavaScript, Bootstrap, and PHP, the project aims to simplify job discovery and improve the overall user experience across different screen sizes.

---

## 🎯 Problem Statement

Finding relevant employment opportunities and navigating job application processes can be challenging for job seekers.

An online job portal provides a centralized digital platform where users can explore job opportunities, view job details, and interact with application workflows.

This project focuses on developing an accessible and responsive interface for these activities.

## ⚙️ Installation & Setup

### Prerequisites

- PHP
- Apache Server (XAMPP or WAMP)
- Web Browser
- Visual Studio Code (optional)

### 1. Clone the Repository

```bash
git clone https://github.com/bhushan0919/Online-Job-Portal.git

cd Online-Job-Portal
```

### 2. Configure Local Server

1. Install and start XAMPP or WAMP.
2. Copy the project folder into the server's web root directory.
3. Start Apache.
4. Configure the database if the application uses MySQL.
5. Update database configuration using your local credentials.

### 3. Run the Application

Open your browser and navigate to:

```text
http://localhost/Online-Job-Portal/
```

The application should now be accessible through your local server.
